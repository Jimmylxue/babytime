## 待发布 · 2026-11-06（系统设置 + 育娃圈公开分享 / 楼中楼评论）

本轮改动：

### 系统设置与原图上传

- 新增 `system_settings` 键值表和后台「系统设置」页；页面按服务端配置定义自动分组渲染，后续加开关只需在 `SystemSettingsService` 的 `SETTING_DEFINITIONS` 里追加
- 首个开关：瞬间「允许上传原图」，默认关闭。关闭时新版本小程序发布瞬间只选择压缩图，减少小服务器的上传流量和存储
- 新增公开配置 `GET /api/system/config`；后台读写 `GET/PUT /api/admin/system/settings`
- 每次设置变更写 `admin_audit_logs`（action=`update_system_settings`），后台页显示最后修改人和时间
- 开关只影响新版本小程序；旧版本客户端仍可能上传原图

### 育娃圈公开分享

- 瞬间新增 `visibility`（family/public）；宝宝创建者可在发布时打开「分享到育娃圈」，也可在相册里随时设为私密
- 首页 / 发现页在育娃圈开启时出现入口；发现页入口与其他小应用一致，是四列宫格中的「育娃圈」卡片，使用爱心对话气泡图标
- 公共内容只展示家长昵称/头像，不展示宝宝姓名、生日、精确月龄
- 支持点赞、评论、举报；后台「育娃圈」页支持公开瞬间列表/下架、举报处理（下架内容/忽略）
- 后台系统设置新增「育娃圈」分组，`community.enabled` 默认关闭；关闭后小程序隐藏入口和公开开关，已有公开内容保留但不再展示
- 举报/评论/点赞有频率限制与文本内容安全

### 楼中楼评论与后台互动明细

- 评论升级为「一级评论 + 楼中楼回复」：支持回复一级评论、回复某条回复并展示「回复 @昵称」；只做一层回复，不做无限嵌套
- 删除一级评论时连同其回复一起隐藏，评论总数同步扣减；删除单条回复只隐藏该回复
- 后台公开瞬间列表的「点赞 / 评论」数字改为可点击，点击后才懒加载详情抽屉：
  - 点赞：查看点赞用户头像、昵称、时间
  - 评论：查看评论树、回复、作者和「已隐藏」状态
- 新增受管理员鉴权的 `GET /api/admin/community/posts/:id/interactions`，表格首屏不加载互动明细
- 只改 `moment_comments` 结构，无新建表；存量评论自动视为一级评论

### 2. 生产 SQL

```bash
# 服务器上，仓库根目录：先备份；已执行过的迁移 run-sql 会自动跳过
bash backup-db.sh pre-deploy
bash run-sql.sh docs/sql/system-settings-2026-11.sql
bash run-sql.sh docs/sql/community-2026-11.sql
bash run-sql.sh docs/sql/community-threads-2026-11.sql
```

- 顺序必须是：`system-settings` → `community` → `community-threads`，且都在部署服务端前执行
- `system-settings-2026-11.sql`：新增 `system_settings` 表；校验 `SHOW CREATE TABLE system_settings\G`
- `community-2026-11.sql`：新增 `moments.visibility`、点赞/评论/举报表及索引/外键；校验 `moments` 的 `visibility`、`idx_moments_visibility_created` 和三张互动表
- `community-threads-2026-11.sql`：新增 `moment_comments.parent_id`、`reply_to_user_id`、楼中楼索引和两个外键；校验 `SHOW CREATE TABLE moment_comments\G`
- 缺任一迁移都可能导致探活失败或对应接口 500；存量瞬间默认 `family`、存量评论默认一级评论，无需回填

### 4. 部署顺序与回归检查

1. 执行 §2 的三份 SQL
2. `bash server.sh`（同时构建管理后台）

注意事项：
- 「允许上传原图」「开启育娃圈」默认关闭，服务端部署完成后到后台「系统设置」按需打开
- 原图开关、育娃圈入口和楼中楼 UI 都要等新版本小程序发布后才真正生效；旧版小程序行为不变
- 育娃圈只做一层楼中楼，不做无限嵌套、关注、热榜、点赞/评论通知
- 本轮部署前先确认上一轮 `server.sh` 的探活超时问题已处理，否则仍会中止在 4006 临时实例
