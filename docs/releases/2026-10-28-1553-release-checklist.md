## 待发布 · 2026-10-28（相册支持一次多选上传）

本轮改动：
- 相册页「拍照记录」与首页「照片」快捷入口改为多选：一次最多 9 张（微信 chooseImage 上限）
- 选图后按并发 3 张上传，loading 显示「上传中 x/y」；按用户选择顺序回填并入库
- 单张失败不中断整批：成功几张存几张，结束时提示「已保存 N 张，M 张失败」（首页弹窗文案同样带失败张数）
- 单图位（宝宝头像、宝宝档案、便便 AI、尿布记录、里程碑封面）行为不变

### 4. 部署顺序

只改小程序端，服务端无需重新部署：上传接口仍是单文件 `POST /upload`，多图由客户端并发调用。

```bash
# 本机，构建并上传小程序（版本号按实际填）
bash mini.sh <版本号> "相册支持一次多选上传"
```

说明：新客户端连旧服务端可用（接口未变）；旧客户端也不受影响。
