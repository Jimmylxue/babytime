## 待发布 · 2026-11-12（提审合规开关：发布 / 家庭互动 / 育娃圈）

背景：小程序因「个人主体未开放的服务类目 · 社交-笔记（UGC 记录、分享）」被拒。上个过审版本（11-03）的瞬间只有文案 + 9 图，没有公开分享，也没有点赞/评论；11-06 加了育娃圈公开分享，11-09 又加了家庭时光流点赞/评论，即使育娃圈关闭，相册里仍会显示点赞/评论，整体被判定为 UGC 社交闭环。

本轮把社交面全部接到后台开关上，提审时可以按需要逐项关闭，过审后再按主体/类目情况决定是否打开。

### 改动内容

1. 后台「系统设置」新增两个开关（`SystemSettingsService`，后台页自动渲染，无需改 admin 代码）：
   - `moment.publishEnabled` → 小程序侧 `momentPublishEnabled`，默认 **开**
     - 关闭后：首页照片快捷入口改为进相册；首页「最近的瞬间」空态不再引导发布；相册页隐藏「发布瞬间」按钮和空态发布引导；发布页深链进入会提示并退回相册；服务端 `createMoment` 直接 403
   - `moment.interactionEnabled` → 小程序侧 `momentInteractionEnabled`，默认 **关**
     - 关闭后：家庭时光流不返回 `canInteract`，相册不显示点赞/评论；服务端点赞、评论、评论列表、删评论入口均拒绝
   - 原有 `community.enabled`（育娃圈）保持默认 **关**
2. 配置接口失败时按审核安全默认值处理：发布关、互动关、育娃圈关（`systemConfig.ts` 的 `DEFAULT_CONFIG`）
3. 相册里旧 public 瞬间的「育娃圈公开」标记，在育娃圈关闭时不再显示
4. 保留 11-11 的育娃圈页面兜底：列表页/详情页在开关关闭时直接 `switchTab` 回首页

### 4. 部署步骤与顺序

1. 按 §2 确认 `system_settings` 表已存在（若 11-06 的迁移尚未执行，先执行 `bash run-sql.sh docs/sql/system-settings-2026-11.sql`）

4. 打开后台「系统设置」，确认出现「瞬间 → 允许发布瞬间」「瞬间 → 允许家庭互动（点赞 / 评论）」「育娃圈 → 开启育娃圈」三个开关

| 瞬间 → 允许发布瞬间 | **关闭** |

| 开关 | 状态 |

**操作提醒**

- 改完开关后等待 **≥ 1 分钟**再提审（小程序端配置缓存 60 秒）
- 用没有瞬间数据的干净测试账号提审；审核备注附测试账号和操作路径
- 审核通过前不要打开育娃圈/家庭互动；个人主体长期开启公开 UGC 有下架/封禁风险，需等主体变更为企业/个体户并添加「社交-笔记」类目后再常开
