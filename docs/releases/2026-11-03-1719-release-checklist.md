## 待发布 · 2026-11-03（瞬间升级为朋友圈式信息流）

本轮改动：
- 新增 `moments` 表，`photos` 增加 `moment_id` / `sort_order`：一条瞬间 = 一段文案 + 最多 9 张照片
- 相册页改为瞬间信息流：宝宝头像 + 名称 + 时间 + 文案 + 朋友圈式九宫格（单图大图不裁切、2/4 图两列、其余三列），支持按条删除
- 新增「发布瞬间」页：一次最多选 9 张、可单张移除、500 字文案，也支持纯文字瞬间；点发布才上传并一次性写入
- 旧照片零迁移：`moment_id` 为空的照片在信息流里显示为「无文案单图瞬间」；旧接口 `/photo/timeline`、`/photo`、`/photo/batch-delete` 原样保留
- 首页「照片」快捷入口与相册页「发布瞬间」都进入新发布页；原「拍照即存」流程下线
- 可见范围跟随家庭权限（宝宝创建者 + 家庭成员）；发布后不可编辑文案，只能整条删除
- 删除宝宝 / 注销账号链路补删 `moments`；后台相册指标仍按 `photos` 行统计，口径不变

## 待发布 · 2026-11-03（后台新增成长里程碑分析）

本轮改动：
- 管理后台侧边栏新增「成长里程碑」页：看这个功能有没有人用、用得多不多、谁在用
- 服务端新增两个 admin 接口（沿用管理员登录态）：
  - `GET /api/admin/stats/milestones?days=14|30|90`：总量、使用人数/宝宝、覆盖率、近 7/30 天新增、趋势、分类分布、热门里程碑、行为漏斗
  - `GET /api/admin/milestones/usage?page&pageSize&keyword&sort`：按实际打卡人聚合的使用用户明细，含宝宝、打卡数、首次/最近打卡
- 统计口径：
  - 打卡量与用户数直接取 `baby_milestones`，不依赖埋点；使用人数按 `actor_user_id` 去重（家人代记算实际打卡人）
  - 页面访问 / 海报分享 / 删除来自 `user_events`（milestone_view / milestone_poster_share / milestone_deleted）
  - 已注销用户留下的打卡单独显示为「已注销用户」，不冒记到宝宝创建者名下
- 无表结构变更、无新增环境变量；本次只影响服务端与管理后台，小程序无需发版
