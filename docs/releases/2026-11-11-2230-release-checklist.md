## 待发布 · 2026-11-11（育娃圈提审合规加固）

背景：小程序因「个人主体未开放的服务类目 · 社交-笔记（UGC 记录、分享）」被拒。后台已有「开启育娃圈」开关（`community.enabled` → 小程序侧 `communityEnabled`），本轮补上关闭时的页面级兜底：

- 育娃圈列表页、详情页进入时强制拉取最新配置（跳过 60 秒缓存）
- `communityEnabled=false` 时不再请求社区接口，直接 `switchTab` 回首页，页面上的「育娃圈 / 公开瞬间」文案不会露出
- 开关打开时行为不变；配置接口失败时按安全默认值（关闭）处理
- 不新增接口、不改数据库、不新增环境变量

### 1. 推送代码

```bash
git commit -m "feat: 育娃圈关闭时列表页和详情页直接回首页"
git push origin main
```

### 4. 部署步骤与顺序

1. **确认生产服务端已包含「系统设置 / 育娃圈」功能**（2026-11-06 批次）。未部署时 `/system/config` 不可用，小程序会按 `communityEnabled=false` 处理，育娃圈对所有人隐藏。
2. 服务端已就绪则只需发小程序：`bash mini.sh <版本号> "育娃圈关闭时直接返回首页"`
3. 提审前：后台「系统设置 → 育娃圈 → 开启育娃圈」保持**关闭**，并确认提交版本后等待 ≥1 分钟再提审（配置缓存 60 秒）。
